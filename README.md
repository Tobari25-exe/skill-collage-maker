# 素質コラメーカー

素質名を検索し、素材画像の文字帯を切り出して文章を合成するローカルWebアプリです。
画像840枚と `data/catalog.json` を同梱しています。OCRやJSONの自動生成は行いません。

## 起動方法

Python 3.10以上を使用し、`Git/` ディレクトリ内で実行します。

```bash
python -m pip install -r requirements.txt
python -m uvicorn app:app --host 127.0.0.1 --port 8765
```

ブラウザで <http://127.0.0.1:8765> を開きます。Windows/Mac/Linux用の簡易起動スクリプトは総合ZIP内の `作業用/起動用/` にあります。`Git/` と `作業用/` を同じ親フォルダに展開して使えます。GitHub Pagesにファイルをアップロードするだけでは動作しません（Pythonサーバーが必要です）。

## 公開用画面

文章の入力、**ひらがな・カタカナを区別しない** チェックボックス、画像を作成・候補を引き直す・画像を保存の3ボタンと結果画像のみを表示します。画像高さは810px固定です。

## 検索仕様

常時有効の表記の吸収:

- **全角・半角**: `Ａ` と `A`、`ｶ` と `カ`、`ｶﾞ` と `ガ` など
- **大文字・小文字**: `A` と `a` など（1文字が複数文字に展開する特殊な変換はしない）
- **記号の表記差**: `！`/`!`、`？`/`?`、`～`/`〜`、`、`/`,`、`。`/`.`、全角/半角の括弧・数字・一般的な記号、各種ダッシュなど

オプション（チェックボックス、初期OFF）:

- **ひらがな・カタカナを区別しない**: `か` と `カ`、`が` と `ガ` などを同一視する

緩和しないもの:

- 漢字の読み（`花` ⇔ `はな`）、似た字形（`力` ⇔ `カ`）
- 小書き文字と大きな文字（`ャ` ⇔ `ヤ`）
- 濁点・半濁点の有無（`か` ⇔ `が` ⇔ `ぱ`）
- 長音符とハイフン（`ー` ⇔ `-`）

空白の削除はしません。ただし**全角空白と半角空白は幅の差として吸収**します。
表記の吸収は検索だけに適用します。出力には**素材画像の元の文字**が残ります。

候補の優先順位:

1. 作成できる文字数が最大
2. **使うカード片数が最少**
3. **元の文字表記との違いが最少**（同じカード数なら元の文字を優先）
4. 出力右端に使う素材の末尾一致を優先
5. 出力左端に使う素材の先頭一致を優先
6. 完全同点ならランダム選択

素材のタイトル途中から切り出す場合、不要な前後の文字は削ります。左端がタイトル先頭と一致する場合は画像左端まで、右端がタイトル末尾と一致する場合は画像右端まで表示します。

未収録文字が残るときは画像を生成せず、不足文字を知らせます。生成結果を描き直すことや不足文字を文字フォントで補うことはありません。

## API

- `POST /api/search`: `{"text":"削除への復活","kana_insensitive":false}` → 検索プランJSON
- `POST /api/compose`: 同じ入力 → 高さ810pxのPNG
- `GET /api/health`: アプリ状態と素材枚数

`kana_insensitive` は省略時 `false`。必要に応じて `seed`（再現可能な乱数）を指定できます。`/api/compose` では `avoid_signature` を渡すと同点候補から別プランを優先します。

## リポジトリ構成

```text
Git/
├── app.py                 # API・アプリ
├── mosaic.py              # 検索・画像合成
├── static/                # Web画面
├── requirements.txt
├── README.md
├── .gitignore
├── .gitattributes
└── data/
    ├── catalog.json      # 全840枚の文字情報
    └── assets/            # PNG画像840枚
```

`Git/` の中身だけで動作します。検査用のExcel・修正履歴・テストなどは総合ZIPの `作業用/` に分離しています。
素材画像を公開する場合はゲーム素材の再配布条件を確認してください。
